# Create Trains Bedrock — Prototipo 0.3

Add-on experimental para Minecraft Bedrock 1.26.60, inspirado en los trenes de Create Mod.

## Incluye
- Locomotora de prueba montable.
- Llave de ensamblaje y receta para fabricarla.
- Vías, cambios de vía, depósito, estación de ensamblaje y andenes con texturas provisionales.
- Recetas de fabricación para los bloques.
- Movimiento de prueba en línea recta: la locomotora avanza automáticamente cuando está encima de vías y tiene más vías delante.
- Usar la llave crea una locomotora; usarla sobre la estación también intenta crearla encima de la estación.

## Recetas
- **Vías (8):** lingotes de hierro alrededor de un palo en la mesa de fabricación.
- **Cambio de vía:** lingotes de hierro alrededor de una vía.
- **Depósito:** lingotes de hierro alrededor de un cofre.
- **Estación de ensamblaje:** lingotes de hierro, redstone y mesa de fabricación.
- **Andén (6):** losas de piedra y adoquín.
- **Llave:** lingotes de hierro y palos en forma de herramienta.

## Límites conocidos
Esta versión sigue siendo un prototipo, no un port completo de Create Java. Las vías son bloques completos y el movimiento es solo recto; todavía no sigue curvas, no usa cambios de vía para girar, no acopla vagones y no puede convertir una construcción arbitraria de bloques en un tren. El depósito no guarda trenes. Las texturas y compatibilidad deben probarse en el juego. Haz una copia de seguridad de tu mundo.

## Descargar
En GitHub abre **Actions**, elige la compilación más reciente que termine correctamente y descarga el artefacto **Create-Trains-Bedrock-mcaddon**. Extrae el ZIP con ZArchiver y abre el `.mcaddon` con Minecraft. Activa ambos paquetes en la configuración del mundo.

Proyecto no oficial, sin afiliación con los creadores de Create Mod.
